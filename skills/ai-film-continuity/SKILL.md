# AI电影：资产与连续性工作流

把一次性的好看画面变成可接续、可检查的镜头资产。默认中文沟通；镜头提示词按用户指定语言输出，未指定时中文即可。方法源自用户提供的 HELL GRIND 工作流拆解视频，并加入明确标注的制作工程化设计；不是 Higgsfield 官方 Skill 的副本。

## 按任务深度执行

- **单项修复或单镜头**：先定位具体失败，再仅展开相关规则；输出保留项、修改项、完整可用提示词和检查点。不强迫用户先做整片资产库。
- **一场戏或连续镜头**：复用已有角色/场景资产，建立空间、状态和镜头接续，补齐会影响拍摄的缺口。
- **整片工作流**：先建稳定资产索引和状态版本，再按场景推进；记录已处理范围与待处理范围，不因完成模板就声称影片完成。
- **只学习、评审、写提示词**：交付分析和文本；不要自动发起付费生成、改动线上项目或发布。用户已要求生成时，使用当前可用的相应工具完成授权范围内的生成与检查。

## 证据和继承顺序

采用：用户明确要求 → 用户批准的原图/资产/剧本 → 已批准的连续性设定 → 本 Skill 的建议。保留源场次、原名和已存在的 ID；不要凭空补全不可见事实。

每个关键字段区分 `已确认`、`参考可见`、`制作建议`、`待确认`。建议坐标或时长可用于先做方案，但不能冒充测量值或批准状态。缺失信息不影响当前工作时，带假设继续；会改变角色身份或剧情时明确指出未定项。

角色、声音、地点、状态、镜头使用稳定 ID；无既有规则时可用 `CHAR-001`、`VOICE-001`、`LOC-001`、`STATE-001`、`SC01-SH001`。每个镜头引用具体版本和真实路径，不能用“同上”代替将要提交给生成器的必要描述。

## 核心执行流程

1. **读输入并锁定任务**：确认原始参考与生成变体的身份，读取实际文件。提取用户不可变项、允许变化项、镜头用途、时长/画幅及已有批准资产。
2. **建立最小所需资产**：角色身份与状态分开；声音身份与单句表演分开；场景结构与灯光/天气状态分开。需要具体做法时读 [八环节制作方法](references/workflow.md)。
3. **建立空间与状态接续**：以固定物为锚点记录位置、距离、朝向、人物左右关系、运动路径和摄影机所在侧。相邻镜头核对上一镜尾帧状态与下一镜首帧状态。
4. **按风险做预演**：多人站位、跨轴线或复杂调度优先检查站位全景/短预演。没有生成授权时交付预演方案；有授权时使用可用工具制作。简单插入镜头不必增加预演成本。
5. **组装镜头包**：读取 [镜头与资产模板](references/prompt-templates.md)，仅保留当前需要的模块。先写画面可见结果，再用焦段/视角等参数辅助；运动写清触发、受力/接触、响应、终态。
6. **检查实际结果并定点修复**：连续性错误先于美观问题。发现偏差后指出证据和影响，优先改最小范围；记录改动及版本，不覆盖批准母版。尚未生成的方案只做文本检查，不声称已验证音色或视频一致性。

## 八项判定规则

| 项目 | 要锁定的内容 | 典型失败及处理 |
| --- | --- | --- |
| 角色资产 | 主脸、正/背全身、服装配件、身份描述 | 小脸干扰时分离脸部和服装参考；受伤/淋湿等从母版派生 |
| 声音 | 音区、音色、语速、口音、习惯、基准版本 | 固定声音描述只是控制输入；用实际声音跨句验证，不能保证同文同声 |
| 场景资产 | 结构、出入口、锚点、光源、材质 | 缺空间信息时补充相容视角；不为套用 3/4 视角改掉用户原构图 |
| 空间地图 | 世界位置、镜头侧、画面左右、视线 | 不混用世界坐标与画面方向；移动摄影机后重新推导画面关系 |
| 预演 | 人数、站位、路线、朝向、轴线 | 用全景或短预演先暴露冲突；不把一张预演图当作空间保证 |
| 尺度 | 已知尺寸参照、景深位置、相对比例 | 把“巨大”变成可见比较；不能把个案五倍/三十米变成通用标准 |
| 镜头 | 机位、距离、景别、可见范围、焦点 | 不依靠“电影感”或焦段数字；FOV 必须说明轴向及成像尺寸 |
| 物理运动 | 支撑、重量、惯性、接触、痕迹、终态 | 描述可观察因果链；检查视频过程，不只看首尾帧 |

## 严格参考复现

用户要求贴近原图或“一模一样”时，以原图为唯一视觉真值，除非明确选择生成变体。先列不可变的构图、主体占位、透视、材质、时代、光源位置、色相边界、景深、大气透视和反射区域，再写允许变化项。

氛围是连续性的一部分：远景对比随距离如何下降、冷暖光扩散到哪里、哪里应失焦、哪里保持深暗都要具体描述。原图有雨幕、湿润薄霭、霓虹光晕或垃圾袋时，不得用通用负面词禁止这些内容。不要用提升锐度替代质感。图上估计的百分比是辅助约束，原图优先；不承诺生成器逐像素复刻。

## 交付与质量门槛

按请求交付最小完整包：必要资产/状态引用、空间与接续说明、完整镜头提示词、针对性禁止项、可执行检查点和待确认项。整场戏补镜头接续表；仅修一镜时不生成冗长总表。

实际生成后按需检查：

- 身份、人数、服装、伤痕位置/方向及持物手不漂移；主参考和状态版本一致。
- 站位、视线、屏幕方向、出入口、锚点和尺度兼容；跨轴或跳时有叙事依据。
- 同一光源/天气条件下，色彩、照明和反射遵守空间逻辑；故意的时空变化有标记。
- 对白归属、音色、音量之外的声线身份及口型按可用证据检查；无音频证据时记未验证。
- 运动至少检查首段、转折/接触、末段，复杂运动提高采样密度；抽帧不足以证明时序流畅，能播放时连贯检查关键段。
- 实际文件路径、版本和状态可追踪。测试失败只阻止依赖它的批量推进，独立工作仍可继续。

预算不足或工具不可用时，交付已完成部分、具体缺口及下一步，不反复盲抽，也不声称生成已完成。
