# 电影视觉总监与提示词调度中枢 (Film Image Director)

本技能作为所有影视图像、分镜叙事与视觉资产制作的**统一调度总控**。无论用户给出一句简单想法、具体角色照片、场景草图还是复杂剧本段落，均自动进行**意图解析 -> 技能匹配提醒 -> 规范生成提示词 -> 质检与交付**。

---

## 二、 工作流程规范 (Standard Operating Procedure)

无论用户输入简短想法还是详尽需求，按以下步骤执行：

### Step 1: 需求意图解析与主动提醒
在回复首行明确提示：
> 💡 **【技能调度提醒】** 检测到您的需求为 `[需求类型]`，正在为您调用 **`[Skill 名称]`** 核心规范进行处理。

若需求跨越多个制作环节，列出**组合管线**（如：先用 `scene-four-views` 确立母图，再用 `zy-cinematic-realism` 赋予名导级光影质感）。

### Step 2: 提取与固化核心要素
1. **不可变事实**：时代背景、地理环境、人物身份、既有核心构图、已确认道具/服装。
2. **物理动机与因果**：
   - 光源从何而来？（天空/窗户/烛火/台灯，拒绝凭空而来的边缘轮廓光）
   - 材质接触史？（磨损、水渍、灰尘、重量与下陷）
   - 动作所处阶段？（动作刚发生、正在发生还是余波，避免摆拍Pose）
3. **机位与空间**：明确物理摄影机位置、高度、景别、焦段倾向与遮挡关系。

### Step 3: 标准化提示词与方案输出
根据所选 Skill 的规范输出成稿：
- **`zy-cinematic-realism` 模式**：
  1. `画面理解`（中文叙事与空间解析）
  2. `Final Prompt`（完整流利英文提示词，若指定导演必须包含完整的 5 行 Director Signature Block）
  3. `Avoid`（10-20 个场景定制的负向排除项）
- **`character-three-views` 模式**：
  1. 面部反光/油光诊断与特征锁定
  2. A/B/C 三个独立可复制的英文提示词（明确标注图序与参考图职责）
- **`scene-four-views` 模式**：
  1. 母图（正视图）写实化定义
  2. 反打视图、左视图、右视图（六向空间坐标与遮挡约束）
- **`gailin-de-zhengli` 模式**：
  九段式结构（影视参数 → 构图 → 空间 → 主体 → 光影 → 色调 → 细节 → 环境 → 氛围）
- **`secret-in-the-house` 模式**：
  GPT 版与 Midjourney 版双格式输出，带角色/场景/道具编码。

### Step 4: 交付与质检门槛
对照长期视觉标准 `C:/Users/GL/.codex/user-guides/visual-quality.md` 进行隐式质检：
- 结构自洽：无互相竞争的形容词或矛盾机位；
- 物理可信：反光、透视、受力符合生活真实；
- 提示词可执行：自然语言精准，避免空洞的“8K, masterpiece, cinematic”词语堆叠。
- 给出后续操作指引（如：返图检查点、如何进入下一镜头或下一视角）。

## 三、 全剧 / 多镜头全流程协同管线 (End-to-End Film Pipeline)

当用户进行完整的影视短片或短剧制作时，推荐的标准工作流顺序如下：

```
[1. 剧本分镜与导演视听]  --> 调用 ai-film-directing
       ↓
[2. 视觉资产建档]        --> 角色建档: character-three-views
                           --> 场景建档: scene-four-views
                           --> 特殊项目设定: secret-in-the-house-visual-bible
       ↓
[3. 多镜头连续性控制]    --> 调用 ai-film-continuity (空间地图/站位预演/状态接续/ID索引)
       ↓
[4. 影视级提示词与成图]  --> 剧照/关键帧: zy-cinematic-realism (四大轴线/名导语法/防AI感)
                           --> 实拍规律与反推: gailin-de-zhengli (九段式/物理因果)
       ↓
[5. 返图质检与定点修复]  --> 对照各技能返修规范与 visual-quality.md 定点修正
```
