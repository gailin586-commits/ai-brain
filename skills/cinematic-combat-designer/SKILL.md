# AI电影打斗提示词（Cinematic Combat Designer）

> 原案：AIGC肖学长 · 动作调度视听体系  
> 定位：把动作戏与打斗场景写成 AI 可稳定执行的物理调度，优先保证动作清楚、空间稳定、绝不融化。专为 Seedance 2.5 / 2.0、Kling、Runway、AZ8 等高质量视频模型打造。

---

## 一、 为什么 AI 打斗镜头极易“崩坏融化”？

1. **动作因果断裂**：仅写“两人激烈搏斗”，AI 分不清谁攻击谁防御，生成结果必然是肢体交缠、瞬移或互穿模型。
2. **动作堆叠过载**：在单段 4–5 秒内写入“滑铲+飞踢+拔刀+开火”，超出单次扩散运动容量，导致多肢体、瞬移或人物变形。
3. **空间轴线混乱**：未规定双方在画面中的左右站位与朝向，镜头一动角色左右互换、衣服换色、武器错位。
4. **硬核血腥触发审核**：直接写中弹流血、穿孔断肢，必遭平台模型强风控拦截。

---

## 二、 动作导演六大工业级纪律

### 1. 空间轴线与站位锚定（180° Axis Stability）
- **全局攻守方向统一定轴**：
  - 例如：进攻方（我方主角与小队）统一**从画面左侧/南侧向右侧/北侧推进**；
  - 阻截方（守军与Boss）统一**从画面右侧/北侧向左侧/南侧压制**；
- 提示词中显式约束站位：“人物A位于画面左侧前景，人物B位于画面右侧掩体后，双方在画面中轴形成对角交火线，绝不发生左右位置颠倒”。

### 2. 一镜一招与因果闭环（Causal Action Loop）
将复杂的连续交锋拆解为独立的物理因果链：
$$\text{起势（Wind-up）} \longrightarrow \text{接触/碰撞（Impact/Block）} \longrightarrow \text{受力反馈（Reaction/Exit）}$$
- **防融化铁律**：把连招拆成 2–3 个独立分镜：
  - *镜 1（微距蓄能）*：外骨骼启动 / 枪栓上膛 / 储气罐加压；
  - *镜 2（穿透推进）*：破烟猛冲 / 贴地滑铲；
  - *镜 3（接触反馈）*：气浪冲击 / 护甲迸火花击飞。
- 剪辑合体成快节奏高燃连招，单镜头内只做**一次核心动作判定**。

### 3. Speed Ramp 电影级变速规范
实测视频模型对抽象的“变速”二字无感，必须采用**物理细节显式描写**：
```text
[动作起点]瞬间画面骤然降到极慢镜：悬停在空中的雨滴、液压杆接缝迸出的金色火花、翻卷水浪的冠状边缘纤毫毕现；
[动作着地/命中]瞬间画面猛然切回极速：水浪与尘灰扑面而来，冲击波撕裂空气呼啸。
```

### 4. 真实受力反馈（无伤高燃过审机制）
大片的打击感来自于**受力物体的动态位移与环境形变**，而非血腥伤口：
- **护甲防护击中**：护甲表面迸出大片橙金电火花，身体被动能推得后退、捂胸单膝跪倒滑出画框；
- **重炮与气浪冲击**：环形透明压缩空气波横扫，掩体沙袋被掀成土浪，守军如保龄球般双脚离地、平飞撞向两侧墙壁滑落；
- **致盲与压制**：强烈白光爆闪瞬间，全员手臂遮眼、痛苦后撤踉跄；声波震荡波令战术翻滚骤然僵直、双手捂耳倒地；
- **枪械射击**：消音器前端喷射短促淡白气雾，枪口微跳，弹壳跳出，枪身随后坐力后座震颤。

### 5. 环境物理互动力学
打斗必须与地面、天气、光线产生物理咬合：
- 脚掌踩碎积水：水花向四周炸开成一圈水幕；
- 贴地滑铲：湿滑沥青地面被犁开五米长的双道翻卷水浪；
- 爆炸与焰火：烈焰照亮漫天雨丝成橙红亮点，冲击波推得手持镜头猛烈震颤。

### 6. 人物武器归属铁律
- 严格限定各角色专属武器（步枪、发射器、盾牌、对讲机），明确“各人物的武器、装备与服装绝不互相交换”；
- 未成年角色承担指引与触发功能（战术指引、刷卡破门、打爆无人监控探头），不承担肉搏杀伤。

## 三、 标准打斗提示词写作模板

```text
镜头N｜[打斗阶段]（约 [秒数] 秒，职责：[动作打击职责]）
使用：{{攻击方锚点}}{{防御方锚点}}{{场景锚点}}{{武器道具锚点}}
开始时：镜头位于[机位高度与角度]，[攻击方]在画面[左/右]侧保持[持械/起势姿态]，[防御方]在画面[对面方位]依托[掩体/立柱]防守。
主要事件：[攻击方]执行[核心攻击动作：如滑铲/扣动扳机/甩出投掷物]，动作具有清晰物理因果：[命中掩体/护甲接触点]，[受力反馈：迸出火花/气浪掀飞/踉跄倒地]，伴随[Speed Ramp慢镜细节与切回极速描述]，[雨水/碎石/烟雾环境互动]。<[重低音爆鸣/金属撞击/撕裂呼啸音效]>。
结束时：镜头停在[落幅状态]，防守方被压制并[滑出画框/失去重心倒地]，攻击方稳住身形并锁定下一目标。
约束：全程无血迹、无伤口、无残肢，打击表现为纯动能受力位移与火花冲击波；镜头保持高速跟随颤动。
```
