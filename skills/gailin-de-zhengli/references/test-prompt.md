# 首次测试：明代江南雨后渡口

用途：检验“盖林的整理”能否将案例中可迁移的写实机制用于不靠特效的中国古代日常场景。此处只保存待测试提示词；尚无生成返图，不作效果宣称。

> 真人历史剧情片静帧，明代江南临河小镇，雨后拂晓。一艘带旧竹篷的小木船贴近青石河埠，穿洗旧靛蓝交领布衫的船夫单脚踩在湿石阶上，右手拉紧潮湿的麻绳，左手扶一位穿灰白素布长衫、提着旧布包的旅人登岸；旅人的脚尖刚离开船板，船身轻微倾斜，船舷旁荡开两圈小涟漪。机位在岸上斜对船头，高约 1.3 米，40 毫米标准视角，镜头保持水平；左前景是一小段虚焦的湿木船沿，人物位于右侧中景，窄河从左前方延伸到远处，背景为同一时期的粉墙黛瓦、木格窗与低矮屋檐。阴天清晨的漫射天光从画面左上照入；远处一扇门内尚未熄灭的油灯只在门槛附近留下小块暖光，不照亮整条街。粗糙青石有深色湿缝和少量浅水洼，浅水洼只映出邻近屋檐的暗轮廓，油灯仅在其下方的湿门槛留下小片暖色反光；船板有磨亮的踩踏处，衣摆被雨水浸深，麻绳纤维因受力绷紧。整体以青灰、褐木与灰白为主，暖灯仅作很小的视觉锚点；保留肤色层次、织物折痕、木纹与石面粗糙度，明暗自然，轻微胶片颗粒，像在真实地点用自然光拍到的瞬间。画面中无可读文字、无现代电线、塑料、玻璃幕墙、霓虹、清代发式、仙侠飘带、舞台光束、镜面般积水、过度锐化、水印或标志。横幅 16:9。

第一轮只变一个因素：如果返图显得过于精心布景，缩小暖灯面积并让人物动作更不对称；如出现时代混搭，优先锁定屋檐、衣着和船具，再调整质感词。
