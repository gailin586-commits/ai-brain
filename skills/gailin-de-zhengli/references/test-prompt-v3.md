# 明代江南渡口｜单变量返修 v3

基于 `test-iteration-01.md` 的 v2。唯一内容改动：在“主体”段明确船夫两脚落点和身体重心。场景、机位、光线、色彩与材质要求保持一致。生成器画幅另设为 2.39:1；这属于原有冻结规格，不计为新增风格变量。

**影视设备参数：** 真人历史剧情片现场剧照感。ARRI Alexa 35 与 50mm 球面电影镜头，T4；横幅 2.39:1。保留自然镜头边缘亮度衰减，柔和层次，不要高动态范围合成感或变形镜头光晕。

**构图：** 相机在河埠同侧，距人物约四米，机位高约 1.35 米，镜头水平。木船从左下角斜入，只占画面左侧约三分之一；两人位于右侧中景，人物头部与背景深色木门错开。远处石拱桥留在左侧深景，轻微失焦。画面不要对称，也不要让船篷挡住人物动作。

**空间描述：** 明代江南临河小镇，右侧是不规则青石河埠与相连的粉墙、旧木格窗和低瓦檐，左侧是窄河。近处石阶、船身与人物处于同一接触平面；远处只有两三组疏密不齐的屋舍，避免复制般整齐的旅游街景。

**主体：** 一名船夫穿洗褪色的靛蓝粗布短衫。靠岸木船紧贴第一层石阶；他的左脚掌完整踩在船内靠岸侧的横向木踏板上，左膝微屈，右脚鞋底平贴岸边第一层石阶，身体重心从左脚移向右脚，两处支撑点都清楚可见。右手收紧缆绳，左手短暂托住一位灰白布衣女旅人的前臂。女旅人正把身体重心转移到岸上，低头看脚下，另一只手提着旧布包；两人注意力都在登岸，姿势略不对称，没有面向镜头的表演。

**光影氛围：** 雨刚停，清晨云层变薄，一小片天空从画面左后方给人物肩颈和船篷边缘带来柔和侧逆光；脸部只受天空与河面的弱反光补亮。瓦檐下、船舱内保持较深但可辨的暗部。门内的油灯已熄灭，不出现暖色灯斑、光束或无来源的轮廓光。

**色调：** 低饱和的青灰河水、灰白墙面和褐色旧木为主；靛蓝衣物略深于背景，人物肤色保留轻微暖意。对比度主要集中在人物与船沿，不做统一的蓝绿色滤镜、橙青对撞或抬亮的灰黑阴影。

**细节巩固：** 只在靠近镜头的手、衣袖、绳结、船沿和脚下石阶保留清楚纹理。布料在袖口、肩头与膝部有不均匀褪色和受力折痕；木船只在手扶与绳索摩擦处被磨亮，其余表面暗哑；皮肤有自然色差，不磨皮也不把毛孔、污迹夸张到特写程度。远处墙面与桥保留轮廓，降低微纹理和锐化。

**环境：** 雨后石阶凸起处较快变干，低洼石缝仍深湿；只在脚边与门槛凹处留少量不规则浅水，不把整片地面做成镜面。船侧轻触河埠，水面从接触处扩散小涟漪；薄雾只在远处河面，近处空气清透。建筑、衣物和船具保持同一时代，不出现现代设施或清代发式。

**氛围：** 像路过的人偶然看见一次普通登岸，安静、稍带赶路的疲惫，画面有生活重量而非古镇宣传照。不要摆拍姿势、全画面极致清晰、塑料般亮面、舞台打光、夸张烟雾、文字、标志或水印。
