# 仙侠舞剑｜镜头感测试 v1

用户从江南渡口转向新测试题材：古代仙侠舞剑电影剧照。此稿只作为待测提示词，不预判出图分数。采用用户指定的九段结构，明确焦距、光圈、机位、对焦与运动模糊；16:9。取初始案例 G15 的“身体旋转—衣摆—碎石”动作链，但不复制其构图。

**影视设备参数：** 真人古代仙侠电影的动作剧照，Super 35 数字电影摄影机，35mm 球面电影镜头，光圈 T2.8，24 fps、90° 快门角度。镜头随人物转身轻微横摇，焦点锁在剑客的眼睛；面部和握剑的手清楚，离镜头最近的剑尖、飞起的袖缘产生有限的自然运动模糊。横幅 16:9，真实景深衰减，不用夸张变形镜头光晕。

**构图：** 机位高约 0.85 米，距人物约 2.7 米，三分之四侧前方，镜头水平并略向上仰。剑客位于画面中偏右，右手中的一柄中式直剑从人物身前斜向画面左前景，剑尖靠近镜头而轻微失焦，眼睛处于清晰焦平面。一小截虚化松枝遮住左上角，近处石阶形成引导线，远山和残破石门退到柔和背景；人物头部与石门轮廓错开。

**空间描述：** 架空古代中国仙山的废弃观门前，一块真实可行走的粗石平台，后方是残存的灰石门柱、老松与层叠山脊。石台有高低起伏、磨损和少量松针，人物与门柱的大小关系可信。没有现代建筑、日式鸟居或无支撑的悬浮台面。

**主体：** 只有一名成年女剑客，穿灰白色多层粗丝与麻布道袍，深灰束腰，布鞋，长发束起，少量碎发被风带起。右脚掌牢牢踩在石台承重，左脚脚尖贴地旋转，髋与肩顺势转开；右手单手握住一柄细长、双刃的中式直剑，正完成一记横向回身剑式，左手向后展开维持平衡。衣袖和下摆沿旋转方向拖出层次，剑只有一柄，手指数量与握柄关系正确，身体没有反关节或悬空受力。

**光影氛围：** 清晨低角度阳光从画面左后方穿过松枝，给发丝、右肩、剑脊和少量石面形成窄而有来源的暖边光；天空的冷色漫射光从镜头右前方轻轻托起面部。石门背面与树根保持深影。剑锋经过处只让近处薄雾被轻微拨开、几片松针受风旋起，不出现凭空自发光的能量刃、巨大光柱或满画面金色粒子。

**色调：** 冷灰石面、墨绿松树与低饱和灰白衣物占主体，暖金只限于晨光扫过的头发、剑脊和少量尘土。人物肤色自然，暗部保留层次；不做青橙对撞、荧光蓝术法或统一漂白色调。

**细节巩固：** 对焦点在眼睛，面部有自然皮肤色差；握剑处指节因用力微微泛白。剑身是有重量的窄直钢刃，边缘反射来自真实晨光，剑柄与护手符合中式直剑形制。粗丝、麻布和皮质剑鞘各有不同反光与磨损；最清楚的细节留给脸、手与剑柄，远山、石门和松枝递减，不让每粒灰尘都锐利。

**环境：** 右脚发力点附近几片松针与细尘被鞋底带起，漂浮方向与衣摆旋转一致；石台其余部分安静。薄雾只停留在远山与石门之后，人物周围空气清透。落叶、发丝、袖摆与剑的运动方向互相解释，不出现全景式暴风、乱飞碎石或镜面地面。

**氛围：** 一次舞剑练习被摄影机捕捉到的短暂发力瞬间，克制、凌厉、有人体重量和呼吸感。避免海报式站桩、过度摆拍、飘浮脚、额外手臂与武器、塑料衣料、游戏 CG 光效、文字、标志和水印。

返图检查：第一，看 35mm 低机位是否形成可读的前中后景和主体尺度；第二，看面部清晰与剑尖/袖缘局部模糊能否同时成立；第三，看足部、衣摆、尘土和光的因果是否一致。若模型无法实现 90° 快门，不反复堆参数，而以“面部清晰、剑尖与袖缘少量运动模糊”的可见效果判断。
