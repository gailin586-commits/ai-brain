# 生视频 Prompt

## 核心任务

把用户的成片意图和参考资产转化为一份面向 Seedance 2.0 的多行自然语言生视频 prompt。先分配每份可解析参考素材的职责，再设计一段可执行、可观察、符合物理规律的时序变化，最后组织动作、运镜、环境运动、声音和镜头连续性。Seedance 2.0 是统一多模态音视频联合生成模型，提供导演级的表演、光影与运镜控制，并原生支持多镜叙事——在一次生成内完成多个连贯镜头、跨镜头转场与时空跳转，同时保持主体、风格与氛围一致。本 skill 默认按这一原生能力组织画面，不把内容盲目压进一个连续镜头，也不为了拆分而拆分。

上下文存在已定义、能在当前生产链中定位或生成的稳定 `@资产名` 时，按 `reference_to_video` 写。资产 name 本身就是最终 reference handle，直接原样引用即可。只有上下文完全没有可用或已命名的参考资产时才按 `text_to_video` 写，参考位留空；某个身份或内容硬约束既无素材名称、也无可执行产物时，才请求补充。用户要求以单图为首帧、固定首尾帧、延长或编辑已有视频时，重点描述对应的目标状态变化：首尾帧写两帧之间连续可达的变化；延长从原视频最后可见状态、速度、方向、构图、光线和声音接续；编辑写明保留项与修改项。

以 Seedance 2.0 的多模态能力为唯一默认基线：允许组合输入 text、image、video 与 audio，单次最多九张图片、三段视频、三段音频。选择职责完整的最小素材集；实际入口显示更严格的上传限制时，以入口为准。

一次生成的 output 时长为 **4–15 秒**（下限 4 秒、上限 15 秒，在此区间内自由选择）。一份 prompt 对应一次 4–15 秒的生成；这段时长里承载一个连续单镜还是一段多镜叙事，由内容的叙事结构决定，具体判断见「划分 Shot 与选择生成形态」。

最终回复只保留本次生成对应的多行自然语言 prompt——单镜形态对应一个镜头，多镜形态对应一段镜头序列。生成时长、画幅和参考文件上传由 Seedance 2.0 入口的对应字段承载；prompt 中的对应描述需与这些设置保持一致，只描述画面本身。

## 独立职责

本 skill 只依赖当前上下文，独立把一个 shot 的画面意图、表演要求、视觉方向或一个清楚的短视频想法变成可生成的视频指令。输入不需要预先具备剧本、分镜或资产表；允许在一个 shot 范围内补足为了运动成立而必需的状态、节奏和空间关系。

**上下文是否已给出生成段划分，决定本 skill 是否重做形态判断**：

- 上下文附带的分镜表、shot list 或导演意图**已经划好了这次生成的形态**（明确这一次生成是一个连续镜头，还是含哪几个镜头、镜头间什么剪辑关系，或本段属于全片切出的哪一段 ≤15 秒生成），本 skill **直接接收这一划分并落成 prompt**，不重新判断切几个镜头、要不要分段——上游已经按叙事做过这个决策。发现上游划分会导致某段超过 15 秒、或某个生成段承载不下时，指出具体冲突交给用户，不擅自改划。
- 上下文只给出**一个 shot 意图或一个清楚的短视频想法、没有现成的形态划分**时，本 skill 才自己按下面「划分 Shot 与选择生成形态」判断这段内容写成单镜、单次多镜还是分多段。

默认交付边界是当前这一次生成所需的参考映射、时序运动、声音与镜头表达。用户提供完整 scene、故事或全片材料时，只提取当前这次生成需要的信息；用户明确要求多个 shot 时，为每个 shot 分别输出一份自包含 prompt，并重复必要锚点。

## 使用肯定指令

始终描述模型应当生成、保持或改变的目标状态。用速度、方向、幅度、构图、时长、数量和状态等可观察属性压缩生成空间。例如，把运镜要求写成"全程缓慢稳定推镜，主体保持在画面中央"，把参考边界写成"复用动作路径与节奏，人物和场景沿用全局设定"。

最终 prompt 由参考素材、全局设定和镜头段落组成，每一句都指向期望画面或声音。安全与合规红线继续遵守系统规则，由系统层处理。

## 建立参考资产契约

先为每份参考素材指定独立职责，再写镜头。原样使用当前上下文已经定义的稳定 `@资产名`，例如 `@角色身份图`、`@雨夜场景图`、`@奔跑动作视频`；每次引用都写明素材类型与控制职责。资产 name 是 reference 契约，不需要转换成另一套编号。

每份参考至少说明引用标识、素材类型、控制职责、必须保留的锚点、允许调整的部分，以及它作用于全片还是指定 shot。控制职责可从角色身份、服装、场景、道具、风格、构图、动作、运镜、节奏、声音或分镜结构中选择一至数项。

按素材类型分配默认职责：

- 角色图片控制身份、脸部、发型、体型、服装和持物；姿势、背景、光线与构图按照当前镜头设定生成。
- 场景图片控制空间结构、时代、关键布景和主光方向；人物与文字按照全局设定生成。
- 风格图片控制材质、色彩、光影和摄影或渲染气质；具体内容与布局按照当前镜头设定生成。
- storyboard 控制当前 shot 的景别、构图、运镜和文案；最终造型与颜色沿用正式角色、场景和风格设定。
- 动作视频控制动作路径、身体节奏、接触关系和速度；运镜视频控制摄影机路径、机位、节奏与焦点变化；人物、服装、场景和风格沿用全局设定。
- 音频控制明确指定的音色、对白、音乐、节拍、环境声或 Foley；画面内容沿用全局设定与当前镜头描述。

使用职责完整的最小参考集。只有新素材提供了不可替代的身份、空间、运动或声音信息时才加入；每个控制维度指定一个主参考，多个素材共同控制同一维度时写明优先级或各自作用的 shot。

发生冲突时，依次遵守：用户对当前成片的明确要求、角色与关键物体身份锚点、当前 shot 的动作和空间逻辑、场景与道具结构、风格与氛围参考。视频参考复用已经指定的动作、运镜或节奏，人物、场景和风格沿用全局设定；风格参考控制影像表现，画面内容沿用当前主体与场景设定。

## 设计时间变化

把每个 shot 写成一段明确的时间变化。每个 shot 只保留一个主动作或一条连续因果动作链，并用一句话说明主体的起始状态、动作过程、视线或反应，以及结束状态。次要动作只有在强化主动作或因果关系时才加入。

同时区分四类运动：

1. 主体运动：人物、动物、物体实际做什么，速度、方向、幅度和接触关系如何变化。
2. 摄影机运动：机位从哪里开始，沿什么路径、以什么速度移动，结束时形成什么景别或构图。
3. 环境运动：风、水、烟、布料、植被、交通、光影等如何响应主体或环境；只保留能够强化动作、空间或氛围的运动。
4. 声音运动：对白、环境声、动作音效和音乐在哪个动作点出现、增强或停止；只在当前 Seedance 2.0 入口支持原生声音时写入。

需要 Seedance 2.0 原生音频时，分别描述对白、环境声、动作音效和音乐，并把关键声音绑定到动作点，例如接触发生时出现对应 Foley、对白结束后音乐才抬升。提供音频参考时，只复用已经指定的音色、旋律、节拍或声音质感。

让运动服从因果和物理：脚步推动身体位移，转身带动衣摆，接触产生受力反馈，镜头跟拍时主体在画框中的位置相对稳定。静止也是运动设计；需要克制表演时，只保留呼吸、眨眼、发丝或衣料等微动，并让背景与摄影机保持稳定。

写完动作链后按时间码做一次**状态交接审查**：逐段追踪主体左右手、持物、姿态、位置、受力、服装状态、关键道具、HUD 或计数及空间关系。前一段的结束状态必须能直接成为后一段的起始状态；动作占用某只手、改变道具位置或更新数值时，明确可见的释放、交接、放下、保持或更新过程。不允许同一只手同时完成互斥动作、道具无因消失或出现、状态跨镜跳变。击杀、消失、破坏、变形或状态切换等终局动作必须写清最终可见状态、残留物和后续是否还能恢复，不能只写过程特效。若一处交接无法用一句可见动作解释，优先简化动作链，而不是补进更多事件。

状态交接审查是内部质量门槛，不是最终画面的叙事中心。冲突修正后，只把决定成败的少量连续性锚点留在 prompt 中，其余篇幅用于主体的情绪变化、表演节奏、动作力度、镜头响应、光色变化和声音反差。每个 shot 都要有明确的情绪任务，并通过可见表演与视听手段完成；若 prompt 读起来主要是在重复状态约束，或动作正确却没有情绪递进与观看重心，应先压缩约束，再恢复表现力。

单个镜头内的动作复杂度要与它的时长相称：每个镜头集中完成一个主要观看任务；复杂连续动作仍是一条因果链时，按可见阶段安排节奏，优先使用动作参考，并保证前一阶段的结束状态能够自然进入下一阶段。一个镜头内塞进多个主要观看任务时，在机位/时空/视点/节奏的自然断点处划成多个镜头，组织进同一段多镜叙事。

先拆出观众必须看见的叙事节拍，再决定每个镜头的时长与内容。分别为建立、变化、反应或停留保留足够的可读时间；镜头时长服从叙事节拍，不预设默认秒数。整段生成落在 4–15 秒：多镜叙事时各镜头时长之和不超过 15 秒；内容极短、单个镜头不足 4 秒时，整段生成仍取满 4 秒下限（用可读的起止节奏或收尾停留补足），而非生成不足 4 秒的片段；必须表达的内容之和超过 15 秒时，按叙事划成多段、每段 ≤15 秒分多次生成。

在分配镜头前先做**观众理解预算**。每个需要观众新理解的规则、目标、地点、道具功能或胜负条件，都必须获得“建立 → 可见验证 → 结果停留”的时间；剪辑和转场不算理解时间。时间不足时，优先删除或合并概念，不以缩短所有节拍、加快剪辑或增加镜头来硬塞。短段默认只围绕一个核心机制或一条因果链展开，结尾只承担一个主要 payoff（结果、笑点或反转）；只有各节拍仍有充分可读时间时才增加第二个机制或支线。Seedance 2.0 能一次生成多镜，不代表观众在同样时长内能理解更多内容。

## 划分 Shot 与选择生成形态

**本节只在上下文没有现成形态划分、需要本 skill 自己判断时适用**；上游分镜已划好形态时直接执行那份划分（见「独立职责」）。

一个镜头是从一个剪辑点到下一个剪辑点之间的连续观看单位。按叙事必要性划分镜头：机位、空间、时间或叙事视点发生明确变化，或出现多个主要观看任务，或一条连续运镜承载不下当前内容时，才划成新镜头；相邻节拍能在同一机位、空间和连续运动中清楚完成时，保留为一个镜头，不为节奏之外的理由加剪辑点。划镜只看叙事必要性，不用秒数当划镜依据——时长约束作用于整段生成而非单个镜头。

时长与形态按 15 秒上限组织：

- 整段内容 ≤15 秒、构成一个连续镜头时，写成单镜 prompt，让模型一镜演绎。
- 整段内容 ≤15 秒、但包含明确的机位/时空/视点切换或硬切节奏时，在这 15 秒内写成一份多镜叙事 prompt，镜头段落之间写明剪辑关系（硬切/转场），交给 Seedance 2.0 在一次生成内连贯演出并保持跨镜头主体、风格与氛围一致。
- 整段内容超过 15 秒时，按叙事把它划成多段、每段 ≤15 秒，为每段分别编写自包含 prompt，各自生成后在剪辑台拼接。

每个镜头段落内部是连续运动；转场与硬切写在相邻镜头段落之间。prompt 的时间从 `0s` 开始，终点等于本次生成的总时长（≤15 秒）。只在必须对齐既有素材、音乐节拍或精确动作点时使用小数秒。分多段生成拼接时，每段的开始状态要继承上一段、结束状态要能交给下一段；合法变化写在“锚点变化”中。

## 控制细节密度与模型自由度

默认锁定决定成败的内容：参考职责、主体身份、一个主动作、起止状态、摄影机路径、关键空间关系、光色、物理约束和一致性锚点。只选择性补充一个环境响应、一项焦点变化或少量声音事件，把非关键表情细节、背景填充、普通粒子和装饰运动留给模型。

用户需求开放时，提供清楚的运动方向和结束状态，并给模型保留非关键微动作的发挥空间。用户需求明确时，优先保留其动作阶段、节奏、机位和参考映射；只压缩互相冲突、超出时长或超出当前景别可见范围的细节。

全局设定只写一次；shot 只写该时段发生的变化。锚点在某个 shot 中发生合法例外时，增加“锚点变化”说明原因与新状态。

## 输出方式

最终回复仅包含可直接粘贴的自然语言 prompt。使用清楚的标题、换行和空行分隔参考素材、全局设定与各个镜头；一行承担一种职责，并使用完整短句表达。

按以下结构输出，只保留已经填入具体内容的行。单镜形态只出现一个镜头段落；多镜形态在同一份 prompt 内按时间顺序重复镜头段落，段落之间写明剪辑关系（硬切/转场），参考素材与全局设定仍只写一次：

```text
参考素材：
@角色身份图：控制人物身份、脸部、发型与服装；忠实保留稳定外观，允许姿态、表情和光线随镜头变化；作用于当前 shot。
@奔跑动作视频（2-5s）：复用主体动作路径、摄影机运动与节奏；人物、场景和风格沿用全局设定；作用于当前 shot。

全局设定：
视频意图：整段视频从什么状态变化到什么状态，观众最终记住什么。
主体与造型：主体身份、数量、关系、稳定外观、服装、配饰与持物。
场景：主场景、时间、天气与稳定空间关系。
影像风格与调色：一至三个互补风格，以及主色、冷暖、饱和度、反差和调色倾向。
摄影系统：总时长、画幅、帧率、主要镜头感、景深和摄影质感。
运动基调：当前 shot 动作与运镜的速度、幅度、连续性和物理规律。
连续性锚点：跨镜头必须稳定的身份、服装、道具、空间、光色和屏幕方向。
声音设计：对白、环境声、动作音效、音乐与总体混音关系。

Shot｜0-5s｜中景：
摄影机：机位起点、主运镜、速度、路径和结束画面。
构图与光线：主体位置、空间层级、注意力路径、光源方向、软硬、色温及必要变化。
主体动作：起始状态 → 主动作与视线或反应 → 结束状态。
环境运动：与主动作相关的环境、布料、光影或背景运动。
动作强度：静止 / 微动 / 中动 / 剧烈。
焦点：只有对焦保持、rack focus 或景深变化承担叙事作用时写入。
声音：只有声音需要与当前动作精确同步时写入。
锚点变化：只有本镜头合法改变全局锚点时，说明变化原因和新状态。
转场：只有后续存在剪辑或明确片尾处理时写入。
```

实际输出使用具体创作内容替换模板中的解释性占位句。模板中的 `0-5s` 只展示时间码字段格式；实际每个镜头的时间码按叙事节拍分配，从 `0s` 起连续、首尾相接、末镜终点等于本次生成总时长（≤15 秒）。参考素材逐项换行；全局设定保持五至八行；每个镜头段落保持四至七行核心描述。单镜结束在明确画面；多镜在相邻段落间写剪辑关系、末镜结束在明确画面。

reference-to-video 模式必须包含使用稳定 `@资产名` 的“参考素材”和“全局设定”。text-to-video 模式只在上下文完全没有可解析参考时使用，并省略参考素材段。单镜形态包含一个 shot 段落，多镜形态包含按时间顺序排列的多个 shot 段落。每个 shot 段落都要说明摄影机、构图与光线、主体动作、环境运动和动作强度。视频或音频参考使用特定片段时标明时间段；声音设计、焦点、声音同步、锚点变化和转场按实际需要出现。
