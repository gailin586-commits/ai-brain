## 二、 镜头视听母法（依 cinematic-shot-designer 镜头设计师）

全片所有生成分镜必须严格执行以下四条视听铁律：

### 1. 一镜一职与单一主导运镜
- 每个镜头只承担一个明确功能，只保留一条纯粹物理机位运动线（推、拉、横摇、俯冲、升越、急甩）；
- 严禁复合混乱运镜，彻底杜绝画面漂移与模型融化。

### 2. 三段式物理机位结构（每镜必填）
- **`开始时：`** 明确起幅物理高度、景别与构图（如：“贴地 0.4 米仰角”、“水面之上约十米”）；
- **`主要事件：`** 明确主导运镜轨迹、人物动作、光影与背景相对流动；
- **`结束时：`** 明确落幅构图、视线指向与出画出口。

### 3. 微距特写担当（每 15–20 秒 $\ge 2$ 处）
全片质感完全靠微距立住：
- 护目镜镜面反光（流动舱内与火光）；
- 外骨骼按键启动与液压电弧；
- 高尔夫铁杆顶端反光映出屏幕跟踪框；
- 战术小手握拳泛白 / 冲锋枪拉栓行程 / 手指勾动发射器连杆；
- 声波同心圆振膜震散雨幕。

### 4. 背景相对运动与镜头呼吸感
- 载具与奔跑段必须写：舷窗雨丝与灯光向后拉丝、大桥与铁塔拉成连续光带；
- 画面末尾固定约束：`镜头始终在运动或手持微颤，绝不静止成单张照片。`
- 屏幕墙必须写：`流动着动态影像、扫描线与跟踪框，绝无任何可辨识文字与错字。`

## 三、 动作调度母法（依 cinematic-combat-designer 打斗提示词）

全片打戏必须严格遵循物理动作链与合规转译：

### 1. 空间轴线绝对统一定轴
- **进攻方推进线**：统一由画面左侧/南侧向右侧/北侧纵深突击；
- **防守方阻截线**：统一由画面右侧/北侧向左侧/南侧火力压制；
- 双方隔掩体对峙，全片严禁无交代穿轴换位。

### 2. 一镜一招与因果闭环（Causal Loop）
- 动作必须体现：`起势 $\to$ 碰撞/释放 $\to$ 动能受力反馈`；
- 复杂连招拆为独立镜头剪辑，单镜内只做一次核心动作判定。

### 3. 电影级 Speed Ramp 变速标准写法
```text
[动作发力瞬]画面骤然降到极慢镜：悬停在空中的雨滴、外骨骼迸溅的金色电弧、翻卷水浪的冠状边缘纤毫毕现；
[动作落地/命中瞬]画面猛然切回极速：水浪与尘灰扑面而来，冲击波撕裂空气呼啸。
```

### 4. 真实受力反馈（无伤高燃过审机制）
- **绝不写穿孔流血**；
- 护甲中弹：写“护甲表面迸出大片橙色电火花，动能推得捂胸单膝跪倒滑出画框”；
- 重武器命中：写“环形压缩空气波横扫，沙袋掀飞成土浪，守军如保龄球般双脚离地无伤震飞撞墙”；
- 闪光压制：写“纯白强光爆闪，全员手臂遮眼、痛苦后撤踉跄”。

## 四、 AZ8 Studio 与 LibTV 投产对接标准

- **画幅标准**：16:9 横屏，禁止上下加黑边（满画幅纯画）。
- **字幕与包装**：生成阶段“零烧字”，关卡字卡、血条UI、撤离框全部留后期剪辑叠加。
- **声音预留**：生成参数开启音频支持，提示词内用 `<...>` 明确物理环境音与拟声音效。
- **参考节点挂载**：每镜最多挂载 8–12 张高权重核心节点（米洋人脸组 + 爸爸人脸组 + 对应干员 + 核心场景）。
